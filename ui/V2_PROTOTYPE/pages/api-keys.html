API 密钥与接入

后端 Workload API · JWT (Authorization: Bearer)
推荐码
Code状态创建时间复制
接入与契约
Base URL
生产环境：https://api.wes.local/v1
测试环境：https://staging-api.wes.local/v1
鉴权
所有请求须在 Header 中携带 Authorization: Bearer <JWT>。
JWT 通过 POST /api/auth/login 获取，有效期 24h，支持刷新。
响应
统一 JSON 信封：{ "success": bool, "data": any, "error": { "code", "message" } }
HTTP 200 仅表示通信成功，业务错误以 error 字段呈现。
上传
文件上传使用 multipart/form-data，单文件上限 20MB。
支持类型：.xlsx / .docx / .pdf / .md
