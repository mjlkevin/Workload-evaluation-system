# O6 AI 输出质量回归基线说明

> Sprint 3B · RP-048 骨架  
> 目标：AI 输出质量可回归——固定样本集 + 确定性断言 + 失败案例归档，让「AI 回答变差了」能被测试抓住。

## 1. 样本清单

固定样本集位于 `apps/api/src/services/ai/eval/samples.ts`，共 **14 条**样本，覆盖 **8 类场景**：

| 场景分类 | 样本数 | 样本 ID | 说明 |
|---|---|---|---|
| capability_discovery（能力问法） | 3 | cap-001 ~ cap-003 | "你会干什么"/"支持哪些操作"/"你能帮我干啥" |
| greeting（问候语） | 2 | greet-001 ~ greet-002 | "你好"/"Hello!" |
| explicit_report_request（显式报告请求） | 2 | report-001 ~ report-002 | "生成需求解析报告"/"帮我输出需求包" |
| business_consultation（业务咨询） | 2 | biz-001 ~ biz-002 | ERP 模块依赖 / WES 业务口径 |
| attachment_qa_guidance（附件问答引导） | 1 | attach-001 | 附件内容问答 |
| out_of_scope（超范围请求） | 2 | oos-001 ~ oos-002 | "帮我写一首诗"/"今天天气怎么样" |
| knowledge_query（知识库查询） | 1 | know-001 | 显式知识库查询 |
| wes_data_query（WES 数据查询） | 1 | wes-001 | 用户历史项目查询 |

## 2. 断言规则

确定性断言框架位于 `apps/api/src/services/ai/eval/assertions.ts`，共 **6 类断言**：

| 断言 | 说明 | 适用样本 |
|---|---|---|
| `intent_routing` | intent 类型与预期匹配 | 全部 |
| `routing_rule` | 路由规则与预期匹配（若样本指定） | 全部 |
| `answer_length` | 回复非空且长度在 [1, 2000] 区间 | 全部 |
| `capability_facts_bound` | capability 回复不含事实表外越界承诺 | capability_discovery / greeting |
| `out_of_scope_intercepted` | 超范围样本必须命中 unsupported_or_out_of_scope | out_of_scope |
| `report_request_routed` | 报告请求必须命中 harness_report_generation | explicit_report_request |

### capability 事实表边界校验策略

- 启发式检测越界承诺关键词：`写诗`、`作诗`、`编程`、`画图`、`天气预报`、`股票` 等
- 本批为轻量关键词校验，**Sprint 4 升级为语义裁判（LLM-as-judge）**

## 3. 如何新增样本

1. 在 `samples.ts` 的 `EVAL_SAMPLES` 数组中添加新样本
2. 必填字段：`id`、`category`、`message`、`expectedIntent`、`description`
3. 可选字段：`expectedRoutingRule`、`hasAttachment`、`hasLatestV1Artifact`、`clientAction`
4. 若新增场景分类，同步更新 `EvalCategory` 类型
5. 若需新增断言类型，在 `assertions.ts` 中实现并注册到 `runAssertionsForSample`

## 4. 测试运行

```bash
# 运行全部 AI 测试（含基线回归）
npm run test:ai

# 仅运行基线回归测试
npx tsx --test src/services/ai/eval/runner.test.ts
```

## 5. Sprint 4 语义裁判升级路径

| 当前（Sprint 3B） | Sprint 4 升级 |
|---|---|
| 确定性断言（intent/routingRule/长度/关键词） | LLM-as-judge 语义评分 |
| 启发式越界检测（关键词匹配） | 语义事实表对齐度评分 |
| 静态样本集（14 条） | 动态样本扩增 + 失败案例自动归档 |
| 零外部依赖 | 可选接入轻量裁判模型（本地 SLM） |

## 6. 失败归档机制

断言失败时，测试输出自动包含：
- 失败样本 ID 与分类
- 失败断言标签列表
- 详细诊断信息

无需额外文件落盘，测试输出即归档。
