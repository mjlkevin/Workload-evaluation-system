# O10 Batch B+C 人工验收样本

> 执行会话只负责写入期望行为，实际结果栏留空由用户手工验收后回填。
> 验收后更新 `testing.html` 总看板页面。

| 序号 | 用户问法 | 期望行为 | 实际结果 | 验收人 | 验收日期 |
|---|---|---|---|---|---|
| 1 | "你会干什么" | 命中 capability_discovery，走模型辅助回复（基于事实表的自然语言，非旧模板腔） | | | |
| 2 | "你能帮我干啥" | 命中 capability_discovery，走模型辅助回复 | | | |
| 3 | "支持哪些操作" | 命中 capability_discovery，走模型辅助回复 | | | |
| 4 | "你会干什么，还有多组织业务往来怎么理解" | 优先命中 capability_discovery（能力问法优先级高于业务术语），回复中可附带简要业务引导 | | | |
| 5 | 断开模型 API Key 后问 "你能做什么" | 降级为结构化事实表摘要，回复中包含「（以下为能力清单摘要）」标注，不静默假装模型生成 | | | |
| 6 | "生成需求解析报告" | 命中 harness_report_generation，不走 capability 回复 | | | |

## 验收 checklist

- [ ] 模型辅助回复语气自然，不是编号列表式模板腔
- [ ] 回复中未出现未实现能力的虚假承诺
- [ ] 降级路径明确标注「（以下为能力清单摘要）」
- [ ] Batch A 行为未回退：unsupported_or_out_of_scope 仍按 0.85 阈值拦截
- [ ] 问候语 "你好" 仍走本地静态回复（硬口径零变更）
- [ ] 报告显式请求仍正确路由到 harness_report_generation
