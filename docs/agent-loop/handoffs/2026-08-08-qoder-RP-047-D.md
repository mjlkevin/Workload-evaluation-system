## 返工与 Gate D 复审（2026-08-08，B1 阻塞项修复）

### 背景

Gate D 审计结论：逻辑合同全部成立（G1/G3/G4、E1、E2 通过，Codex 独立复跑全绿），

### B1 根因确认（返工前侦察）

1. Shell.jsx（L70-81）引用的 9 组类名（`.shell-background-runs` / `-indicator` /
   `-notifications`、`.background-run-notification` 及 `--completed/--failed/--cancelled`
   三种 kind、`-text`、`-dismiss`）经 grep 验证**全仓 CSS 零定义**。
2. `.shell` 为两列 grid（`208px minmax(0,1fr)`，layout.css L3），`<ShellBackgroundRuns />`
   是第 3 个 grid 子项 → 自动放到第 2 行第 1 列（侧边栏正下方），首行高度 ≥100vh，
   指示器与通知常态不可见；既有测试仅断言文本存在，掩盖了布局问题。

### 修复方案（右下角 fixed 堆叠，零 JSX 改动）

- **可见位置**：`.shell-background-runs` 以 `position: fixed; right/bottom: 16px`
  离开 grid 流，右下角垂直堆叠（指示器 pill + 通知卡列表）；无需改动 Shell.jsx
  与 `.shell` grid 结构，不触发停止条件。
- **样式补齐**：9 组类名全量定义于 `src/index.css`（紧随 Step 5 徽标段）；
  颜色全部用语义 token（`--accent`/`--ok`/`--err`/`--warn`/`--info`/`--surface`
  /`--line`/`--ink*`/`--bg-soft`/`--shadow-*`），零裸色值；三种 kind 修饰类以
  左边框色区分（completed→`--ok`、failed→`--err`、cancelled→`--warn`）。
- **不遮挡主内容**：容器 `pointer-events: none`（子元素 `auto`），空隙处点击穿透；
  `max-width: min(360px, calc(100vw - 32px))` 保证 760px 无横向溢出；通知列表
  `max-height: min(40vh, 320px)` 内滚，不无限堆高。
- **层叠**：新增层阶 token `--layer-float: 40`（tokens.css，additive）——介于
  workspace-tabs(30) 与 drawer(50)/modal(60) 之间；通知不盖弹窗，弹窗不盖通知错层。
  该 token 追加不在原工单 §7 清单，系按 checker `numeric-z-index` 规则指引
  （"Use the shared layer scale"）扩展共享层阶，零存量规则改动，**声明项 10**。
- **ARIA**：`role="region"` + `aria-live="polite"` 保持不变（既有 JSX 未动）。
