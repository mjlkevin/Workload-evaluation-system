## 6. 关键参数（冻结）

- feature flag：`WES_AI_DURABLE_RUNS_ENABLED`，默认 `false`；关闭错误码
  `ASYNC_RUNS_DISABLED`（HTTP 503）。
- SSE 心跳 15s；回放批量上限 200 条/轮；均可注入，默认值由测试守护。
- 删除冲突错误码：`SESSION_HAS_ACTIVE_RUN`（409）。
- 响应 envelope：`{ code, message, data }`；提交成功 HTTP 202，
  `data = { runId, sessionId, status: "queued", eventCursor }`。
- clientMessageId：`metadata.clientMessageId` 承载并原样回读；幂等主键是 submissionKey。

## 13. 风险与声明项

- flag 默认关闭：合入后生产不启用新能力，属灰度设计（Batch E 启用）。
- Worker 不 boot-start：提交的 Run 保持 queued 直到 Batch E；契约测试用测试内
  驱动的 fake workflow 证明链路。
- `waiting` 状态当前无生产写入方：inputs/confirm 契约先行，直接造 waiting 行验证。
- SSE 长连接未压测：批量上限与心跳控制，压测归 Batch E。
- ajv 环境分叉预警（既有看板风险）：若新 worktree `build:api`/测试出现
  `structured-output.ts` 类型错误，先排查 ajv 版本（8.20.0 vs 6.15.0）再归因代码；
  临时符号链接 workaround 若使用必须 gitignored 并在 handoff 声明。
