- 基线漂移（Assignment Commit 与 main HEAD 不一致、基线测试计数不符）；
- Step 0 缓办补测发现既有实现缺陷（触业务即停）；
- dispatch 复用必然牵动既有行为（超出 E2 登记改法）；
- Allowed Paths 之外才能完成需求（含新依赖、DB schema 变更、flag 默认值变更）；
- 既有测试需要修改才能通过（非本批 additive 引起）；
- flag off 行为被迫变更；owner 隔离或权限边界无法保证；
- 主 checkout 出现非预期改动。
