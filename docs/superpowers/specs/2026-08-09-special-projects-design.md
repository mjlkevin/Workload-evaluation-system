# 专项计划页面设计文档

> **项目**: WES-Agent-升级总看板  
> **页面**: 专项计划 (special-projects.html)  
> **设计日期**: 2026-08-09  
> **设计师**: Qoder  

---

## 1. 页面定位

在 WES-Agent-升级总看板的【计划与设计】一级导航下新增"专项计划"子页面，用于集中展示和管理项目开发中的各类专项行动（架构优化、功能优化、外部参考借鉴优化等）。

该页面为**只读展示型**静态 HTML 页面，数据由 Qoder 在专项立项时按约定格式登记，经人工审核后合并入版本控制。

## 4. 各 Section 详细设计

### 4.1 Section 1: 页面头部

复用现有 `.doc-h` 样式：

```html
<header class="doc-h">
  <div class="doc-wrap">
    <div class="crumb">计划与设计 / 专项计划</div>
    <h1>专项计划</h1>
    <div class="meta">
      <span>专项总数 <b>6</b></span>
      <span>进行中 <b>3</b></span>
      <span>已完成 <b>2</b></span>
      <span>已归档 <b>1</b></span>
      <span>更新于 <b>2026-08-09</b></span>
    </div>
  </div>
</header>
```

### 4.2 Section 2: 专项看板

#### KPI 卡（4 列网格）

| 卡项 | 数值示例 | 图标颜色 |
|------|---------|---------|
| 专项总数 | 6 | brand（默认） |
| 进行中 | 3 | accent（橙色） |
| 已完成 | 2 | ok（绿色） |
| 本月新增 | 1 | teal（青色） |

复用 `.kpi-row` + `.kpi` 组件，每个 KPI 卡包含：图标、标签、数值、副标题、底部进度条。

#### 执行中专项快照表格

复用 `table` 组件，展示当前状态为"进行中"的专项：

| 列 | 说明 |
|----|------|
| 专项编号 | 如 SP-2026-001 |
| 主题名称 | 专项标题（加粗） |
| 类型 | pill 标签（架构优化/功能优化/外部参考借鉴） |
| 负责人 | 姓名 |
| 状态 | `.status.run`（进行中） |
| 进度 | 百分比进度条 |

### 4.3 Section 3: 专项清单

#### 工具栏

复用 `.tbl-tools` 样式：

```html
<div class="tbl-tools">
  <input type="text" class="tbl-search" placeholder="搜索专项名称、编号或负责人...">
  <select class="tbl-filter"><option>全部类型</option><option>架构优化</option><option>功能优化</option><option>外部参考借鉴</option></select>
  <select class="tbl-filter"><option>全部状态</option><option>待启动</option><option>进行中</option><option>已验收</option><option>已归档</option></select>
  <span class="tbl-count">共 6 项</span>
</div>
```

> **注**：搜索/筛选/排序为纯前端交互，通过 JavaScript 实现（不依赖后端）。

#### 全量表格

| 列 | 宽度 | 说明 |
|----|------|------|
| 专项编号 | 100px | 等宽字体，如 SP-2026-001 |
| 主题名称 | auto | 加粗显示 |
| 类型 | 100px | pill 标签，带颜色区分 |
| 治理内容 | 25% | 简短描述，悬停显示完整内容（title 属性） |
| 时间线 | 160px | 开始日期 → 结束日期 |
| 负责人 | 80px | 姓名 |
| 当前状态 | 90px | `.status` 组件 |
| 关联文档 | 120px | 链接列表 |

**状态颜色映射**：
- 待启动 → `.status.todo`（灰色）
- 进行中 → `.status.run`（蓝色，带脉冲动画）
- 已验收 → `.status.done`（绿色）
- 已归档 → `.status.warn`（黄色）

**类型颜色映射**：
- 架构优化 → `.pill.brand`（蓝色）
- 功能优化 → `.pill.acc`（橙色）
- 外部参考借鉴 → `.pill.ok`（绿色）

### 4.4 Section 4: 专项统计分析

#### KPI 卡（4 列网格）

| 卡项 | 数值示例 | 说明 |
|------|---------|------|
| 整体完成率 | 67% | 已完成+已归档 / 总数 |
| 平均执行周期 | 14 天 | 已完成专项的平均耗时 |
| 成功率 | 85% | 按时完成占比 |
| 活跃趋势 | ↑ 1 | 本月新增 vs 上月 |

#### 时间线趋势

复用 `.timeline-card` 样式，展示近 6 个月的专项立项/完成趋势（用简单的 div 条表示数量）。

### 4.5 Section 5: 专项档案

采用 `.tech-detail`（折叠面板）组件，分三个子区域：

#### 子区域 A: 进行中专项协作信息（默认展开）

每个进行中专项一张卡片，包含：
- 专项名称 + 状态 pill
- 参与人员列表（头像 + 姓名 + 角色）
- 联系方式（飞书/邮箱链接）
- 最近更新动态（1-2 条）

#### 子区域 B: 已完成专项归档（默认收起）

表格形式，包含：
- 专项名称
- 完成时间
- 成果摘要
- 经验总结文档链接

#### 子区域 C: 最佳实践案例（默认收起）

卡片列表形式，每个案例包含：
- 案例标题
- 适用场景
- 关键要点（3-5 条 bullet）
- 参考专项链接

## 5. 数据维护约定

### 5.1 Qoder 登记格式

Qoder 添加新专项时，在 Section 3 的表格 `<tbody>` 中按以下格式追加行：

```html
<tr data-sp-id="SP-2026-001">
  <td class="mono">SP-2026-001</td>
  <td><b>AI 工作台意图路由重构</b></td>
  <td><span class="pill brand">架构优化</span></td>
  <td title="将意图路由从硬编码改为 Skill 层解耦，支持动态注册与优先级排序">将意图路由从硬编码改为 Skill 层解耦...</td>
  <td class="mono">2026-08-01 → 2026-08-15</td>
  <td>张鹏</td>
  <td><span class="status run"><span class="dot"></span>进行中</span></td>
  <td><a href="...">设计文档</a> · <a href="...">PR</a></td>
</tr>
```

### 5.2 编号规则

专项编号格式：`SP-YYYY-NNN`
- `SP` = Special Project（专项）
- `YYYY` = 年份
- `NNN` = 年度内序号（3 位，不足补零）

示例：SP-2026-001, SP-2026-002, ...

### 5.3 状态流转

```
待启动 → 进行中 → 已验收 → 已归档
   ↑______________↓
        (可回退)
```

## 6. 样式与交互

### 6.1 样式复用

| 样式来源 | 复用内容 |
|---------|---------|
| `base.css` | CSS 变量、基础排版、wrap/doc-wrap |
| `components.css` | 导航、KPI、表格、状态、折叠面板、卡片、时间线 |
| `pages.css` | 页面级布局微调（如有） |

**不新增任何 CSS 文件或样式规则**，所有视觉效果均通过复用现有类实现。

### 6.2 交互行为

| 交互 | 实现方式 |
|------|---------|
| 页面加载动画 | `board-ui.js` 自动处理 `.reveal-pending` |
| 表格行悬停 | `components.css` 的 `tbody tr:hover` |
| 技术细节折叠 | `data-tech-collapse` + `board-ui.js` |
| 搜索筛选 | 内联 JavaScript（`<script>` 标签，约 30 行） |
| 排序 | 表头点击排序（内联 JavaScript） |

### 6.3 响应式

自动继承现有断点：
- **> 1040px**: 4 列 KPI、3 列资源卡、完整表格
- **680px - 1040px**: 2 列 KPI、1 列资源卡、表格横向滚动
- **< 680px**: 1 列 KPI、1 列资源卡、表格横向滚动、导航折叠
