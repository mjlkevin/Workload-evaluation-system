# 限时活动

> 来源：https://platform.kimi.com/docs/pricing/promotion.md

## Kimi K2.7 Code 发布限时充值活动

**活动时间**：2026-06-12 00:00:00(UTC+8) – 2026-07-02 23:59:59 (UTC+8)

### 活动内容

单笔充值满 ¥500 即享阶梯赠券：

| 单笔充值金额 | 赠送比例 |
|------------|---------|
| < ¥500 | 0% |
| ¥500 – ¥1999 | 20% |
| ¥2000-¥4999 | 25% |
| ≥ ¥5000 | 30% |

### 规则说明

- 每个组织ID仅可参与一次，只返一笔赠券
- 选取活动期间内首次充值当日金额最高的交易按比例计算返赠
- 返赠档位按实际到账金额计算，向下取整至元
- 赠券在充值后1个工作日内发放，单张最高2万元
- 赠券可用于全部消费，有效期90天
- 消费时优先扣减代金券余额
- 充值金额不支持退款
