# 定价与计费

> 来源：https://platform.kimi.com/docs/pricing/

## 计费基本概念

**Token**：1 个 Token 大约相当于 1.5-2 个汉字。可通过计算 Token API 预估。

**计费逻辑**：Input 和 Output 均按量计费。文件相关接口限时免费。

### 联网搜索定价

| 工具名称 | 计费单位 | 价格 | 说明 |
|---------|---------|------|------|
| 联网搜索 | 1 次 | ¥0.03 | 触发 `$web_search` 工具调用计费一次 |

联网搜索计费逻辑：
- `finish_reason = tool_calls` 且 `tool_call.function.name = $web_search` 时收取 ¥0.03
- `finish_reason = stop` 时不收取调用费用
- 搜索结果计入 Tokens，在下次调用时计费
- 总计费：`total_tokens = prompt_tokens + search_tokens + completions_tokens`

### 限速概念
- **并发**：同一时间最多处理的请求数
- **RPM**：每分钟最多请求数
- **TPM**：每分钟最多交互 Token 数
- **TPD**：每天最多交互 Token 数

> 代金券不计入累计充值总额
