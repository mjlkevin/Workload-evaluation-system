# 使用控制台进行批量推理

> 来源：https://platform.kimi.com/docs/guide/use-batch-inference.md

批量推理允许你通过 Kimi 开放平台控制台提交大规模推理任务，无需编写代码。

> 注意：批量推理针对某一项目进行，只有 Tier1 及以上的用户可以使用。如更倾向于通过 API 进行批量处理，请参考 Batch API 指南。

## 操作步骤

### 1. 创建批任务
进入 **用户中心** → **项目管理** → **查看项目** → **批量推理** → **创建批任务**。

### 2. 配置任务参数
- **批量任务名称**：为任务设置名称
- **最长等待时间**：选择任务最长等待时间
- **数据文件**：上传新文件或选择已有文件

### 3. 等待推理完成
任务提交后开始执行，可在列表中查看任务状态。

### 4. 下载输出结果
任务完成后，点击 **详情** 查看详细信息并下载输出结果文件。

### 5. 查看历史文件
在项目的 **文件** 页面可找到历史上传的输入文件和输出结果文件。
