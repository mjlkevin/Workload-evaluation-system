# 建立并认证你的组织 & 官方工具

> 来源：https://platform.kimi.com/docs/guide/org-best-practice + /guide/use-official-tools

## 组织管理

### 组织 ID
注册登录开放平台后，在【组织管理】-【组织认证】页面找到组织 ID。

### IP 白名单
- 组织级安全配置，个人认证和企业认证均可使用
- 白名单为空时不限制 API 调用来源
- 最多配置 20 条 IP/CIDR
- 仅支持公网 IPv4 地址
- 不支持 IPv6
- 保存时整体覆盖原有配置

**入口与权限：**

| 认证状态 | 入口展示 | 可配置成员 |
|---------|---------|-----------|
| 未认证 | 不展示 | 无 |
| 已个人认证 | 展示 | 当前账号 |
| 已企业认证 | 展示 | 组织创始人、管理员 |

**IP 格式示例：**
```
203.0.113.4
198.51.100.0/24
52.94.76.0/22
```

**无效示例（无法保存）：**
- 内网地址：`192.168.1.1`、`10.0.0.1`、`172.16.0.0/12`
- 回环地址：`127.0.0.0/8`
- 链路本地：`169.254.0.0/16`

### 项目管理

**项目余额及限速：**
- 组织下所有项目共享组织限速
- 组织下所有项目共享账户余额

**项目消费管理：**
- 可设置月/日消费预算
- 可设置消费提醒（短信通知）
- 可独立配置项目 TPM 限速
- 实际限制执行约有 10 分钟延迟

**项目个数限制：**

| 组织类型 | 项目个数上限 | API Key 个数上限 |
|---------|-----------|---------------|
| 未认证 | 1 | 10 |
| 个人认证 | 20 | 50 |
| 企业认证 | 50 | 100 |

### 成员管理

**组织成员：**
- 企业管理员：可创建项目、邀请管理成员、开具发票
- 普通成员：仅可查看项目

**项目成员：**
- 项目管理员：管理预算/限速/消费通知/邀请成员/创建 API Key
- 普通成员：仅查看项目/创建 API Key

## 官方工具

Kimi API 提供以下官方内置工具：

### $web_search（联网搜索）
- 类型：`builtin_function`
- 功能：联网搜索互联网信息
- 使用时必须禁用思考能力
- 定价：每次调用 ¥0.03

### 工具声明方式

```python
tools = [
    {
        "type": "builtin_function",
        "function": {"name": "$web_search"},
    },
    # 可与普通 function 共存
    {
        "type": "function",
        "function": {
            "name": "my_tool",
            "description": "...",
            "parameters": {...}
        }
    }
]
```
