### 🎨 Foks — 前端工程师

#### T1: 评审前端最小闭环（D1-D3，优先级 🔴）

**背景**：后端 `/api/v1/teams/:teamId/reviews` 已就绪，前端评审页需要补齐最小闭环。

**任务**：
1. **评审列表页**（`app/dashboard/review/page.tsx` 改造）
   - 展示评审名称、关联总方案、状态徽章（待评审/通过/驳回）、创建时间
   - "新建评审"按钮
   - 点击行进入详情页

2. **创建评审弹窗**
   - 选择团队（dropdown）
   - 选择总方案版本（dropdown，加载用户最新 GL- 版本）
   - 评审说明（textarea）
   - 提交调用 `POST /api/v1/teams/:teamId/reviews`

3. **评审详情页**
   - 展示评审基本信息
   - 评论列表（评论人、内容、时间）
   - 新增评论输入框 + 提交按钮（`POST /api/v1/teams/:teamId/reviews/:reviewId/comments`）
   - 状态操作按钮：关闭评审（`PATCH /api/v1/teams/:teamId/reviews/:reviewId/status`）

4. **权限控制**
   - 非团队成员评论返回 403 提示
   - 仅评审创建者可看到"关闭评审"按钮

**API 参考**（后端已就绪）：
```
GET    /api/v1/teams/:teamId/reviews
POST   /api/v1/teams/:teamId/reviews
GET    /api/v1/teams/:teamId/reviews/:reviewId
POST   /api/v1/teams/:teamId/reviews/:reviewId/comments
PATCH  /api/v1/teams/:teamId/reviews/:reviewId/status  {status: "closed"}
```

**验收标准**：
- [ ] 可创建评审并出现在列表中
- [ ] 可新增评论并实时显示
- [ ] 可关闭评审且状态更新
- [ ] 非授权用户操作有 403 提示
- [ ] `npm run build:web` 通过

**预计工时**：3 天
