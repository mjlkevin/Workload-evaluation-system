**复核结论：确认未落地，清单描述准确。**

  3. 补一个回归测试：async 路由 handler 抛错 → 断言返回统一 `{ code, message, data }` 500 结构而非挂起。
- 验证：`npm run build:api`、`npm run test:modules`、新增回归测试通过。
- 注意：版本兼容（`express@4.21` + `express-async-errors@3.x`）。
