- **构建脚本**：利用 tree-shaking 特性，精简构建产物，降低部署包大小

#### 可能的应用场景与实施建议

- **落地方式**：渐进式替换——先在新模块中使用 es-toolkit，再逐步迁移旧代码
- **引入成本**：低（提供完整 Lodash 兼容层，API 基本一致）
- **预期收益**：构建产物体积显著减小，运行时性能提升，依赖维护成本降低
- **风险提示**：需验证兼容层是否覆盖 WES 当前使用的所有 Lodash 方法；建议先在小范围模块试点
