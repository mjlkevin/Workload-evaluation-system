核心边界：AI/Harness 可以生成报告、建议动作和传统草稿；正式评估、正式需求、正式项目推进必须经用户人工确认/编辑。确认动作通过 enter_formal_estimation 触发，且仅在 report_v2_ready 阶段允许执行，按 run/action 幂等返回既有结果。
API
外部视觉工具边界：Napkin 作为 server-side integration 接在 Harness 编排之后，用于把售前页面计划生成 PPT/PNG/SVG 视觉资产。调用前需要用户确认，调用中记录 request/status/download ToolEvent，完成后立即下载到 WES 自有导出目录；前端不得直接持久化或展示 Napkin 临时文件 URL。

后置能力：人工确认回写 Harness 审计已作为 Phase 1F 交付；向量库、Prompt Profile CRUD、标准治理 Harness 化和更高 Agent 自主级别仍不属于当前 1F 范围，需要在回写链路稳定并完成人工验收后单独评审。Embedding 厂商与向量存储策略后续确定。
