Section 01

Section 03

人工测试反馈

人工测试用于补足自动化无法覆盖的真实业务体验、权限感知和边界提示。当前测试计划已建立，执行结果需要在测试页按任务 ID 回填。

指标当前值目标管理入口
P0 主链路任务0/6全部通过后才可声明人工主链路完成。MT-1E-001 ~ MT-1E-006
P1 边界任务0/4通过或有明确延期决策。MT-1E-007 ~ MT-1E-010
P2 巡检任务0/2记录优化项，不阻断主链路。MT-1E-011 ~ MT-1E-012
失败 / 阻断反馈0P0/P1 问题进入风险页或变更页。结果反馈模板
监控口径自动化测试绿色只能证明工程底座通过；人工测试未执行前，不把 Phase 1E 的真实业务体验标记为人工验收完成。

Section 08

后续指标

Reliability

模型 schema 失败率

按 provider、报告类型、sourceFile 类型统计，观察 prompt/schema 是否稳定。

Workflow

草稿确认转化率

v2 报告生成后，用户点击 nextAction、进入草稿、完成确认的漏斗。

Audit

追溯完整率

抽样检查 ToolEvent output 与传统草稿链接是否可互相追溯。

Runtime

边界完整率

抽样检查 Harness Run 是否具备 source、execution、artifact、delivery 和 knowledge reference 的最小闭环。

指标含义用途
任务运行时边界完整率每个 Run 是否可明确关联来源文件、用户补充、模型执行、产物、草稿链接和人工确认回写。防止 AI 工作台退化为不可复盘的普通聊天；详见 任务运行时。
LLM 调用完成率上传文件后是否真实创建 modelRun，并得到 schema 校验后的 artifact。防止 AI 工作台退化成纯代码拼装的“秒回假分析”。
人工答案覆盖率v1 缺失项中有多少被用户补充并进入 v2 answeredQuestions。衡量高交互式工作流是否有效。
模块/需求匹配度模型识别出的模块和需求与人工标准答案的匹配比例。作为 Harness Regression 的核心质量指标。
Section 09

Trace 留存策略

分层保存业务产物长期保存；详细 raw trace 保存较短周期，例如 90 天；评分摘要长期保存。这样既能支持审计和 Regression，又避免无限膨胀模型输入输出原文。
对象建议留存说明
业务 artifact长期file_understanding、requirement_report_v1/v2、澄清摘要、草稿链接。
ToolEvent长期所有写动作和确认动作的审计依据。
Regression 评分摘要长期用于版本间模型质量趋势分析。
raw model trace短期，例如 90 天用于排障、prompt 调优和争议复核，到期可脱敏归档或删除。
