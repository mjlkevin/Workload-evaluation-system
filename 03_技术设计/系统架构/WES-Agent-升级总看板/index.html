Phase 1G 交付状态

Phase 1G 已把 AI 工作台从固定评估流水线升级为受控任务运行时：文件上传提供上下文，用户意图决定是业务问答、附件问答、WES 数据查询、报告生成还是写动作确认。v1 后普通追问不再自动生成 v2，结构化卡片提交或明确报告意图才推进报告链路。

Phase 1G 交付口径intent runtime
  • 1F 基线：人工确认后回写 Harness ToolEvent 与 metadata。
  • 1G 原则：文件是上下文，用户意图才触发工作流。
  • 1G 路由：已覆盖能力发现、业务问答、附件问答、报告生成、WES 查询、写动作确认。
  • 1G 边界：普通追问不再自动生成 v2，卡片提交或明确意图才推进报告。
  • 1G 审计：关键模型回答保留 trace，写动作继续记录 ToolEvent。
  • 仍不引入向量库、Prompt Profile CRUD、标准治理 Harness 化和低代码设计器。
