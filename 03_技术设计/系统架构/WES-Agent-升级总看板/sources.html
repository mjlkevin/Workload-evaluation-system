03 / Truth Flow

事实流转图

代码事实优先，文档承接事实；汇报看板从事实源抽取，而不是反过来定义实现。

01 apps/api Express + modules 模式；Harness 首个 DB-backed 域；AI 工作台 WES 数据查询已支持 owner-scoped 项目状态摘要与 project trace refs；附件问答已返回并持久化 trace.modelRun 轻量审计；RP-007 已新增 Harness regression sample schema 与 requirement_match_v1 评分规则
02 ui/V2_PROTOTYPE Vite + React；AI 草稿接回传统工作台；AI 工作台右侧工作区折叠状态已记忆，Artifact Workspace 已支持来源/执行/产物/交付时间线，Markdown 表格与 unsafe link/raw HTML 已做渲染层防护
03 实现与文档对齐说明.md 记录 V2 设计与实际实现的差异
04 docs/openapi.yaml 对外 API 契约从实现导出，含 LightweightModelRunTrace 与 KnowledgeToolTrace
05 升级总看板/* 可视化汇报与审计入口
06 审计 / 汇报 / Review KIMI Review、后续 Phase 规划
核心原则：代码与运行路由是最高优先级事实源。当 openapi.yaml、产品技术方案.html 与代码实现冲突时，先修文档再交付；总看板只呈现已对齐的事实，不创造新的事实。
