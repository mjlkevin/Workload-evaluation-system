03 / Truth Flow

事实流转图

代码事实优先，文档承接事实；汇报看板从事实源抽取，而不是反过来定义实现。

01 apps/api Express + modules 模式；Harness 首个 DB-backed 域
02 ui/V2_PROTOTYPE Vite + React；AI 草稿接回传统工作台
03 实现与文档对齐说明.md 记录 V2 设计与实际实现的差异
04 docs/openapi.yaml 对外 API 契约从实现导出
05 WES 项目管理/* 可视化汇报与审计入口
06 审计 / 汇报 / Review KIMI Review、后续 Phase 规划
核心原则：代码与运行路由是最高优先级事实源。当 openapi.yaml、产品技术方案.html 与代码实现冲突时，先修文档再交付；项目管理页只呈现已对齐的事实，不创造新的事实。
